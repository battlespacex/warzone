# StratOps / Warzone Project Rules

## Core Rule
Do NOT break existing working functionality.

## Workflow
- Always inspect before editing
- Explain root cause first
- Make minimal changes only
- Do not refactor unrelated code

## Critical Areas (HIGH RISK)
- auth / login
- routing
- global scripts
- API calls
- build config

## UI Rules
- Do not change styling unless asked
- Respect existing class names
- Keep layout intact

## Output Rules
- List changed files
- Explain what changed
- Explain how to test

## Safety
- If unsure → ASK before editing
