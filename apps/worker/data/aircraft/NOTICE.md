# Military aircraft identity reference

This directory contains the unmodified `plane-alert-mil.csv` from SDR-Enthusiasts/plane-alert-db at the commit recorded in its manifest. The manifest records its SHA-256, Git blob hash, import timestamp, validation rejects and duplicate counts. The original upstream copyright and licence notice is in `LICENSE`.

Source: https://github.com/sdr-enthusiasts/plane-alert-db

Contents licence: Database Contents License, https://opendatacommons.org/licenses/dbcl/1-0/

Exact reference matches are community-supported evidence, not independently verified current ownership, a live position or a replacement for provider observations. Keep attribution/provenance on enriched observations. Review public redistribution obligations before publishing a derived database; do not ship this directory in browser assets.

Import into a new directory with `scripts/import-military-aircraft.mjs`, review validation, then deliberately select the reviewed snapshot. Normal application startup performs no upstream registry download when this pinned bundle is present. An explicitly configured legacy source URL retains its existing refresh behavior.
