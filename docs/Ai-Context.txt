Purpose
-------
This file gives any AI assistant, developer, or technical collaborator immediate working context for the Warzone project so they can help without needing repeated explanations from the project owner.

Brand and Product Relationship
------------------------------
Warzone is a BattlespaceX product and should always be understood in that context.

BattlespaceX is the parent defense-news and OSINT wires platform / brand.
Warzone is the dedicated military-style global conflict monitoring and OSINT visualization command center under that brand.

Brand relationship:
• Parent platform: BattlespaceX
• Product / sub-platform: Warzone
• Main brand site: battlespacex.com
• Product deployment: warzone.battlespacex.com

When writing copy, modal content, summaries, or product descriptions, it should be clear that:
• Warzone is powered by / launched by / built by BattlespaceX
• BattlespaceX is the umbrella brand
• Warzone is the specialized operational visualization environment


Product Overview
----------------
Warzone is a high-performance global conflict monitoring and OSINT visualization command center powered by BattlespaceX.

It visualizes open-source signals, reported military activity, and emerging strategic events on a 3D Cesium globe through a cinematic command-center interface.

The platform is designed to support situational awareness and conflict observation through public-facing, OSINT-informed visualization rather than generic news presentation.

The visual and functional character of the platform is closer to a military operations dashboard than a traditional web map.

Typical platform capabilities include:
• missile strike arcs
• drone / UAV activity
• military aircraft tracking
• naval vessel tracking
• airspace alerts and sirens
• cyber indicators
• thermal or anomaly signals
• escalation indicators
• event hotspots
• live or near-live event streaming
• heatmap mode
• layer controls
• regional filtering
• detection / threat range visualization


Positioning
-----------
Warzone should be described as a premium, military-style, OSINT-informed situational awareness platform.

It is not a generic news map.
It is not an official warning network.
It is not a command-and-control system.
It is not a verified intelligence product.

It is a public-facing operational visualization environment that transforms fragmented open-source signals into a clearer, structured, and visually coherent battlespace picture.

Useful positioning language:

Frontend Module Map
-------------------
The frontend is modular. The most important files are below.

assets/js/index.js
Application entry point.
Initializes UI, globe, app logic, live subscriptions, and dev tooling.

assets/js/essential.js
Main application controller.
Responsibilities:
• application boot
• event normalization
• UI rendering
• region filtering
• layer filtering
• syncing events to globe
• hotspot integration
• military track integration
• viewport-based event fetching
• handling incoming realtime events

assets/js/warzone-globe.js
Cesium rendering engine.
Responsibilities:
• globe initialization
• imagery / labels setup
• event rendering
• missile arc visualization
• impact pulses
• alert-region highlights
• viewport bounds reporting
• map mode switching

assets/js/warzone-hotspots.js
Handles DOM-based hotspot cards tied to map positions.

assets/js/warzone-military-tracks.js
Handles aircraft, drone, and naval movement rendering.

assets/js/warzone-layers.js
Layer definitions, UI state, layer filtering, and persistence.

assets/js/warzone-region-selector.js
Region modal, region selection logic, and camera-based / viewport-based filtering.

assets/js/warzone-realtime.js
Supabase realtime subscriptions for new events and active alerts.

assets/js/warzone-ranges.js
Operational detection / threat range visualization layer.
Intended for AWACS, fighters, carriers, destroyers, SAM / air-defense style events, etc.
Styling should be controlled through CSS root tokens rather than hardcoded values.

assets/js/warzone-siren-alert.js
Stacked siren and warning banner system.

assets/js/warzone-sticky-alert.js
Persistent active alert bar.

assets/js/warzone-dev-panel.js
Development-only test event launcher.

assets/js/warzone-ui.js
General UI tab / panel interaction binding.

assets/js/warzone-boot.js
Loader, intro modal, dock widget interactions, fullscreen, modal tabs, and widget show/hide behaviors.

assets/js/supabase.js
Supabase client connection.

assets/js/home-anchors.js
Home / UI anchor behavior.
