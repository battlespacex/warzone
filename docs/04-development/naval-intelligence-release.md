## Implemented

- DVIDS `/search`: server-only key, Navy/news discovery, four pages of 50 per cycle, ascending publication cursor with one-day overlap, stable source/external-ID upserts, timeouts, request isolation and capped backoff. Up to ten older stored items are rechecked by documented `id` search per cycle; missing/no-longer-naval records become withdrawn. This is bounded reconciliation, not instantaneous removal notification. DVIDS publication and media timestamps are never equated with ship observations.
- One scheduled worker job, single-flight per process, normally hourly (minimum 30 minutes). Run only one ingestion process for this job; distributed scheduler coordination is not implemented. Missing key makes zero DVIDS requests. No source collection occurs in browser requests.
- Approved structured imports from any eligible registry country: `NAVAL_INTEL_IMPORT_FILE`, a private UTF-8 JSON array, at most 500 records / 5 MB. `NAVAL_INTEL_APPROVED_SOURCES` is a comma-separated list of independently approved official source IDs. Review/approval is still required. Noncommercial, paid-contract, member and permission-required entries remain blocked even if listed. There is no automatic website scraping, PDF extraction, imagery vessel detection or optional AIS-provider activation.
- Import record fields: `source_id`, `external_id`, `title`, `summary`, `source_url` (HTTPS within that registry source domain), `published_at` (ISO UTC), `event_type`, optional `vessel_name`, `navy_country_iso2`, `group_name`, `hull_number`, `vessel_class`, `region`, `region_code`, `observation_at`, `valid_until`. Geometry needs validated GeoJSON Point/Polygon/MultiPolygon, `geometry_role` and `geometry_evidence`. Observed points require observation time. Named regions stay nonmap records. Port reference points never become live vessel positions.
- New additive private `naval_source`, `naval_evidence`, `naval_activity` tables; RLS blocks browser/database-key reads. Identity metadata stays with activity payloads; it does not create or modify live AIS identities, history or GLB assignments.
- Premium-authenticated `/naval-intel/events`, `/summary`, `/event/:id`, following existing API mount conventions (not a second `/api` prefix). Bounded 90-day / 1,000-candidate snapshot, shared 60-second process cache, 100-event response cap, bbox/since validation, explicit truncation and unavailable states. Complete archival pagination/search is not implemented.
- Existing Naval toggle automatically loads an independent reported-activity panel after region entry settles. Historical/operating-area filters, source links and expandable evidence use existing widget classes. Only published geometry renders, at most 40 records / four parts per record. Named-region reports remain in the list; no guessed points/polygons, moving OSINT ships or new GLBs. The existing live AIS panel/filter remains independently functional; no new consolidated Live AIS checkbox is added. No per-frame work or browser polling timer. Refresh occurs on enable/region settlement; expiry is local.
- OFF aborts pending requests, removes only the owned data source/widget, destroys click handler and clears timers. Permanent listener cleanup is provided by `disposeNavalIntelligence`.
